# Learn Git/GitLab/GitHub

This repository is dedicated to learning Git.

We are going to learn Git step by step.

## 1. What is Git?

Git is a **Version Control System (VCS)**.

Git is a tool that tracks changes to files over time. These files can be source code, projects, documents, or any other files that need to be tracked.

Git is software that runs on your computer. You can use Git without GitHub or GitLab.
