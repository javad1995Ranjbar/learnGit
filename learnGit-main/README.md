# Learn Git/GitLab/GitHub

This repository is dedicated to learning Git.

We are going to learn Git step by step.

## 1. What is Git?

Git is a **Version Control System (VCS)**.

Git is a tool that tracks changes to files over time. These files can be source code, projects, documents, or any other files that need to be tracked.

Git is software that runs on your computer. You can use Git without GitHub or GitLab.
## 2.Github
GitHub is a platform/service for hosting Git repositories and collaborating with other people.
## 3.GitLab
GitLab is another platform that can host Git repositories and provides additional DevOps functionality.
GitLab is particularly common in organizations because it can provide things such as:
    * Git repository
    * CI/CD
    * Issue tracking
    * Container Registry
    * Security tools
    * DevOpsworkflows
